WORKFLOW QUANTORA CI
--------------------
- Disparadores: pull_request -> main, push -> main, workflow_dispatch.
- Permisos mínimos: contents: read. Sin secretos, sin tokens personales.
- Runner: ubuntu-latest, Bun 1.4.0 (setup-bun oficial), instalación con
  bun install --frozen-lockfile (integridad del lockfile).
- Un único job "quality" (una sola instalación de dependencias):
  1. Checkout
  2. Setup Bun (1.4.0)
  3. Versiones (bun, node si existe)
  4. bun install --frozen-lockfile
  5. git diff --check
  6. Protección de archivos privados (git ls-files)
  7. Tests de dominio
  8. Tests de intake
  9. strategies:validate
  10. Pipeline: strategies:build + strategies:report
  11. Estado del workspace (solo catalog.json regenerado)
  12. Build cliente y SSR (vite build; regenera src/routeTree.gen.ts)
  13. Typecheck (bun x tsc --noEmit)

CONTROL DE SEGURIDAD
--------------------
check-private-files.sh (solo archivos versionados con git ls-files):
- Falla si hay .mq5/.ex5/.set/.dll versionados.
- Falla si hay .env, .env.local o .env.* versionados (.env.example se
  permite expresamente).
- Falla si hay credenciales, claves privadas (.pem/.key/.p12/.pfx,
  id_rsa/id_ed25519, .git-credentials, .netrc) o archivos de configuración
  con token/secret/credential en el nombre.
- En caso de fallo imprime solo las rutas, nunca el contenido.
